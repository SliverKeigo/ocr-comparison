# OCR 对照台

给百度 OCR 识别结果补上可视化对比的小工具。

## 为什么做这个工具

使用百度文字识别在线体验时，我拿到了识别文字和 JSON 结果，但希望能像阿里云的体验界面一样，直接对照原图查看识别效果，而不用逐条核对 JSON 中的文字和坐标。

因此创建了这个仓库：导入原图和 OCR 返回的 JSON，把识别文字按原始坐标放回图中，直观检查错字、漏字和位置偏差。

## 功能

- 四种查看模式：原始图像、纯识别文字、文字叠加原图、原图与文字并排对照。
- 按 `location` 中的坐标、宽度和高度还原识别区域。
- 搜索识别文字，点击列表或图中区域联动定位，查看坐标详情。
- 调整文字颜色、不透明度和识别框，支持缩放及拖动画布。
- 按原始分辨率导出当前视图为 PNG，也可复制全部识别文字。

纯浏览器处理，不调用 OCR 服务，不上传导入的图片或 JSON。适用于百度 OCR 返回的 `words_result` / `location` 结构，也可用于输出相同结构的其他识别服务。

## 运行

需要 Node.js 18 或更新版本，无需安装依赖。

```sh
npm run dev
```

浏览器打开 http://localhost:4173 。可以通过 `PORT=8080 npm run dev` 指定其他端口。

## 使用

1. 点击「导入文件」，选择原始图像。
2. 选择 JSON 文件或粘贴识别结果。更换 JSON 时可以继续使用当前原图。
3. 点击「开始对比」，在原图、识别结果、叠加对比、并排对照间切换。
4. 点击图中文字或左侧识别项，查看对应位置和坐标。可搜索、调整文字颜色与不透明度、显示识别框、拖动及缩放画布。
5. 点击「导出视图」下载当前模式的 PNG，保留原图分辨率。并排模式会将两张图合并；导出会保留文字颜色、不透明度和识别框设置，排除临时选中高亮。

支持的 JSON：

```json
{
  "words_result": [
    {
      "words": "已日",
      "location": {
        "top": 23,
        "left": 1031,
        "width": 66,
        "height": 30
      }
    },
    {
      "words": "3110812026",
      "location": {
        "top": 55,
        "left": 1024,
        "width": 154,
        "height": 45
      }
    }
  ]
}
```

`location` 使用原始图片像素，左上角为原点，`top`、`left` 不小于 0，`width`、`height` 大于 0。文字根据每个区域的宽、高排版，不改变原始坐标。支持多行文字以及带其他元数据的 OCR 返回结果。图片与坐标尺寸不匹配时，底部会显示越界区域数量。

默认示例使用提供的报名表原图，示例 JSON 是根据参考效果手工整理的演示数据，并非 OCR 引擎的实际返回值。刷新会恢复示例；导入文件不会保存到服务器或浏览器持久存储。

## 构建与测试

```sh
npm test
npm run build
```

`dist/` 为可部署到任意静态托管服务的产物。请通过 HTTP 服务访问，浏览器直接打开 HTML 文件会限制 ES 模块和示例数据读取。
